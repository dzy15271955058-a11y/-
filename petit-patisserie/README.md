# 小甜屿 · Petit Patisserie

一个以旋转欣赏和轻互动为主的甜品网站。11 款风格化立体蛋糕、甜品与饮品，由 Three.js 实时构建，支持拖拽旋转、缩放、暂停、重置和全屏。

## 甜品与小互动

| 甜品 | 互动 |
|---|---|
| 苹果小圆舞 | 移出一角，观察分层，再放回 |
| 蜜桃小皇冠 | 果冻蜜桃轻轻弹跳 |
| 玫瑰云朵 | 浅粉渐变糖花展开、收拢 |
| 给你一颗心 | 心形慕斯轻轻跳动 |
| 午夜黑玫瑰 | 点亮、熄灭烛光 |
| 草莓奶油小屋 | 打开、关上饼干小门 |
| 一小片草地 | 小草随风摇摆 |
| 橙光千层 | 分层展开、合拢 |
| 晴空布丁杯 | 果冻回弹 |
| 云朵气泡蓝 | 密集气泡翻涌、跃出杯口，冰块轻晃 |
| 青提小花园 | 金色桂花打旋飘落 |

这是欣赏型互动体验，不包含下单、支付或自由装饰编辑器。模型是从参考图提炼的风格化造型，不是照片自动重建，也不模拟真实食品物理。

## 运行

这是纯静态网站，无需 API Key、数据库、npm 安装或构建。所有运行模块均放在 `dist/vendor/`，不依赖第三方 CDN。把 `dist/` 部署到静态主机即可。

本地若已安装 Python，在项目根目录运行：

```bash
python -m http.server 8000 --directory dist
```

然后打开 `http://localhost:8000`。由于使用 JavaScript 模块，不要直接双击 HTML 文件运行。

## 文件

- `dist/index.html`：页面内容与结构。
- `dist/style.css`：配色、排版、手机布局。
- `dist/models.js`：11 款甜品数据、三维几何和互动动作。
- `dist/app.js`：旋转、缩放、选择、动作、全屏与状态。
- `dist/soft-renderer.js`：无 WebGL 设备的轻量软件投影。
- `dist/assets/icons/`：统一视角、透明底的甜品小图标，由本项目模型渲染；来源见 `ASSETS.md`。

## 体验与验证范围

现代浏览器支持 WebGL 2 时显示带阴影、反光和玻璃材质的三维模型。WebGL 不可用时自动改用同一几何的 Canvas 投影，仍可旋转和互动，但玻璃、阴影、平滑度和帧率会有差异。两种模式均尊重系统减少动态设置；用户仍可以主动播放或触发小动作。

已检查本地资源、模块语法、11 个模型的几何坐标与互动变换，并渲染轻量模式检查遮挡与造型。本次未进行云端浏览器端到端测试；GPU 材质、触摸和全屏效果仍需在实际设备确认。

原创代码与模型渲染图标采用 MIT 许可；Three.js 按其 MIT 许可分发。网站和源码包均不包含用户上传的参考照片。

如需重新生成图标，可在本地安装可选的 `@napi-rs/canvas`，然后运行 `node scripts/render-icons.mjs`。该工具只读取项目的模型代码，不读取参考图；网站运行和 GitHub 发布不需要它。
